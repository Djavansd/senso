Política de Privacidade do Senso

Versão 1.0 - atualizada em 15/01/2025

Esta política explica como o Senso trata dados pessoais usados no app de gestão de clientes, serviços, orçamentos, agenda e financeiro. Ela deve ser adaptada com os dados reais do responsável pelo app antes do uso público.

1. Quem controla os dados

O responsável pelo negócio que usa o Senso decide quais dados de clientes serão cadastrados e para quais finalidades. Esse responsável atua como controlador dos dados pessoais cadastrados no app.

2. Dados que podem ser tratados

  • Dados de conta: e-mail, identificador do usuário e informações de plano.
  • Dados de clientes: nome, telefone, endereço, CPF ou CNPJ, veículo, placa e cor.
  • Dados operacionais: serviços, orçamentos, agenda, histórico e financeiro.
  • Dados da empresa: nome, telefone, endereço, documento e logo para orçamentos.

3. Finalidades

  • Permitir o cadastro e a organização de clientes e atendimentos.
  • Gerar orçamentos, históricos, agenda de retorno e controle financeiro.
  • Sincronizar os dados entre dispositivos quando o usuário está autenticado.
  • Controlar acesso, plano contratado e segurança da conta.

4. Onde os dados ficam

Os dados podem ficar salvos no navegador do usuário, por meio de localStorage, e também podem ser sincronizados no Firebase/Firestore quando existe login ativo. O Firebase é uma infraestrutura da Google usada como prestadora de armazenamento, autenticação e banco de dados.

5. Compartilhamento

O Senso não vende dados pessoais. Dados podem ser compartilhados apenas com prestadores necessários para o funcionamento do app, como Firebase/Google, ou por obrigação legal. Quando o usuário abre WhatsApp para falar com um cliente, os dados enviados passam a seguir também as regras do WhatsApp.

6. Direitos dos titulares

O titular pode solicitar acesso, correção, exclusão, portabilidade, informações sobre uso dos dados e revogação de consentimento quando aplicável. O responsável pelo negócio deve manter um canal de atendimento para esses pedidos.

7. Retenção e exclusão

Os dados devem ser mantidos somente pelo tempo necessário para prestação do serviço, cumprimento de obrigações legais, defesa de direitos ou outra base legal aplicável. A exclusão ou correção dos dados pode ser solicitada pelo canal de contato informado nesta política. Após a solicitação, o responsável pelo app avaliará o pedido e poderá excluir ou corrigir os dados, conforme aplicável.

8. Segurança

O app usa autenticação, regras de acesso por usuário no Firestore e validações de entrada. Ainda assim, o usuário deve proteger sua senha, manter os dispositivos seguros e evitar compartilhar acesso com terceiros.
